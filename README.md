# NAGOMI CAFE

架空の和風カフェを想定して制作したレスポンシブWebサイトです。

## 公開サイト

https://nnhh0201.github.io/nagomi-cafe/

## 使用技術

- HTML
- CSS
- Flexbox
- Media Queries
- GitHub Pages

## 制作内容

PC・スマートフォンの両方で閲覧できる、
和をテーマにしたカフェサイトを制作しました。

ABOUT、MENU、CONCEPT、ACCESS、CONTACTの
各セクションを実装しています。

## 工夫した点

- 和の雰囲気に合わせた配色
- Hero画像上の文字を読みやすくするグラデーション
- Flexboxを使用したレイアウト
- Media Queriesによるレスポンシブ対応
- Google Mapsの埋め込み
- PCと実機スマートフォンでの表示確認

## 制作を通して学んだこと

HTMLの構造設計からCSSによるレイアウト、
レスポンシブ対応、GitHubへのアップロード、
GitHub Pagesでの公開まで一連の流れを経験しました。
